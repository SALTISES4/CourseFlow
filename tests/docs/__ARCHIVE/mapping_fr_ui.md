# Mapping  FR ↔ UI

Mapping used by the functional requirement language to UI / implementation (e.g. MUI icon component names).

## Icons — Edit Section (workflow)


| Name in FR   | Icon ID in UI        |
| ------------ | -------------------- |
| Insert below | AddCircleOutlineIcon |
| Duplicate    | ContentCopyIcon      |
| Delete       | DeleteOutlinedIcon   |
| Comment      | CommentOutlinedIcon  |
